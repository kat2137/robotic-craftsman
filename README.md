An opensource project aiming to recreate craft through a robotic arm. 
The project uses a robotic arm design developed by Katarzyna Długosz, a WiLoR arm recognition pipeline, volunteer videos and analysis to recreate handstitching using the robot arm. While the project is currently in progress, all CAD files and scripts will become publicly available once finished.

Motion logic is based on Theory of applied robotics : kinematics, dynamics, and control / Jazar, Reza N.
The project uses WiLoR database for finger joint mapping from images and video.
